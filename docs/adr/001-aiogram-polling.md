# ADR 001. Telegram: aiogram и long polling

- **Статус:** принято
- **Дата:** 2026-09-10

## Контекст

Бот должен получать сообщения из Telegram и отвечать на них. Для этого есть два пути: long polling и webhook.

Нужно самое простое решение, чтобы проверить идею диалога. Отдельный веб-сервер, публичный URL и настройка HTTPS на старте не нужны.

## Решение

Используем библиотеку **aiogram** и метод **long polling**: бот сам периодически запрашивает у Telegram новые обновления.

Webhook на этом этапе не используем.

## Последствия

- Запуск — один процесс: `make run`. Не нужен веб-сервер и туннель.
- Бот должен быть запущен постоянно, пока с ним общаются.
- Если позже понадобится выкладка на сервер с постоянным адресом, можно заменить polling на webhook. Это отдельное решение.
