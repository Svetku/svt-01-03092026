## Итерации

### 1. Запуск бота

- [x] Каркас проекта и настройки из `.env`
- [x] Бот поднимается через `make run` и слушает Telegram
- [x] **Проверка:** процесс живой, в stdout есть старт

### 2. Команда `/start`

- [x] Короткое приветствие без обращения к модели
- [x] **Проверка:** `/start` → текст в чат, в логе команда и `chat_id`

### 3. Ответы LLM

- [ ] Роль из системного промпта, ответ на текстовый вопрос
- [ ] Если модель недоступна — короткая фраза в чат и ошибка в логе
- [ ] **Проверка:** вопрос → ответ в роли; без ключа — понятная ошибка, не падение

### 4. Память и `/reset`

- [ ] История чата в памяти процесса (до 20 реплик)
- [ ] `/reset` очищает только этот чат
- [ ] **Проверка:** уточняющий вопрос опирается на прошлое; после `/reset` контекст пропадает

### 5. Нетекстовые сообщения

- [ ] Фото, стикер, голос — без ответа в чат и без записи в историю
- [ ] **Проверка:** стикер молчит, в логе `chat_id` и тип вложения

### 6. Docker и смена провайдера

- [ ] Запуск через `make docker-run`
- [ ] Смена провайдера тремя переменными в `.env`, без правок кода
- [ ] **Проверка:** бот работает в контейнере; после смены URL/ключа/модели диалог жив
